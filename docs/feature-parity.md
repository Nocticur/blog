# 参考项目功能补齐说明

本项目保留现有黑白首页与静态构建方案，新增以下内容能力：

- `/dynamic/`：动态内容集合，支持置顶、标签和草稿。
- `/life/notebooks/`：笔记本与 Markdown 条目。
- `/life/routines/`：日常规划，支持状态和时间字段。
- `/life/places/`：离线足迹记录，支持经纬度和照片字段，不依赖地图密钥。
- `/calendar/`：文章发布日与生日/纪念日月历。
- `/pengyou/`：构建时读取配置的公开 RSS/Atom，并按链接去重。
- `/timeline/`：构建时读取 Git 提交历史。
- 文章分享菜单：生成 PNG 分享海报。

动态示例和生活记录示例放在 `src/content/` 下，并标记为 `draft: true`。正式内容可以直接复制这些文件的 frontmatter。朋友圈 RSS 源在 `src/config/pengyouConfig.ts` 配置，单个源超时或失败不会阻断构建。

本次没有恢复番剧收藏、樱花/壁纸特效或 AI 搜索，也没有新增第三方密钥。在线文章编辑沿用现有 `/writing/`，新增集合可先通过内容文件管理；这些集合的编辑器接入应复用同一认证与 Git 提交流程后再开放。
