# 博客写作页（/writing/）实施计划

## 目标
在导航栏「文章」下拉（文档 → 归档 → 图谱 之后）加「写作」入口，进入 `/writing/` 写作页：密码登录 → 我的文章列表（新建 / 编辑 / 删除）→ 写作编辑器（元信息表单 + Markdown 工具栏 + 编辑/预览双栏）→ 点发布后文章写入 `src/content/posts/`，dev 热更新立即出现在站上。界面结构与逻辑参考 Firefly-hyde `/adminmn/` 的写文章页（登录卡 → 居中表单卡 → 工具栏 + 双栏预览 → 保存/取消），视觉用博客自身设计语言实现。**不做完整后台管理**（无说说/笔记本/仪表盘）。

## 关键约束与决策
- 博客是纯静态 Astro，「直接发布」= dev server 提供本地写入 API（Vite 插件 `configureServer`），仿照现成 `scripts/new-post.js` 写 `.md` 文件。**线上部署打开写作页：能过密码门，但提示「仅本地开发模式可发布」**（静态站无 API）。
- 密码门双端生效：配置里存 SHA-256 哈希（不把明文打进前端包）；客户端 WebCrypto 比对决定是否进编辑器，dev API 每个请求带 `x-writing-auth` 头由 middleware 校验（防止绕过页面直接调接口）。
- 图片不做上传，标题/封面/摘要等均为表单字段；正文插图手动填相对路径（现有惯例 `./image/<slug>.assets/…`）。

## dev API（astro.config.mjs 内联 Vite 插件，仅 dev 生效）
- `configureServer` 里同步 `server.middlewares.use("/api/writing", …)` 拦截；实现时验证拦截先于 Astro handler（若被抢先则调整注册方式）。
- 鉴权：所有请求校验 `x-writing-auth` 头等于 `writingConfig.passwordHash`，否则 401。
- `GET /posts`：遍历 `src/content/posts/**/*.md`（跳过 assets/image 目录），gray-matter 解析，返回 `{file,title,published,draft,category,tags,description}` 按 published 降序。
- `GET /posts?file=x`：返回 `{frontmatter（日期序列化为 YYYY-MM-DD）, content}` 供编辑预填。
- `POST /posts`（新建，重名返回 409）/ `PUT /posts`（按 file 覆盖更新）：frontmatter 字段 title/published/updated/description/image/tags/category/draft/lang；`matter.stringify` 后把 quoted 日期修正为 `published: 2026-06-14` 字面量（与现有文章一致，保证 z.date() 解析）；文件名 slug 校验与越界防护照抄 `scripts/new-post.js` 的正则 + 前缀判断。
- `DELETE /posts?file=x`：删除（确认目标在 posts 目录内且为 .md）。
- JSON body 手动收集解析，不新增依赖。

## WritingStudio.svelte 状态机
- **login**：密码输入 → sha256 与 prop 比对 → sessionStorage 存 hash → 进入 list。
- **list**：GET 列表；请求 404/网络失败 → **offline** 态（密码门后显示「静态部署无法发布，请在本地 `npm run dev` 使用写作功能」）。每行显示标题/日期/分类/草稿徽标；操作：新建文章、编辑、删除（confirm 后 DELETE + 刷新）。
- **editor**：
  - 元信息卡：标题、slug 文件名（按标题自动推导、可编辑、校验同 new-post.js）、分类（datalist 提示现有分类）、标签 chips 输入、日期（默认今天）、摘要、封面路径、草稿开关。
  - 正文卡：工具栏（H2/H3、粗体、斜体、引用、行内代码、代码块、链接、图片占位、列表）+ textarea + 双栏实时预览（用已有依赖 `marked`；正式 remark 管线更重，预览为近似渲染）。
  - 操作：发布/保存（POST/PUT）→ 成功回列表并提示已上站；Ctrl/Cmd+S 快捷保存；取消返回。
- 样式：oklch 变量 / Tailwind / 现有卡片与按钮风格；`manualChunks` 把 WritingStudio 拆到 `vendor-writer`（仿 vendor-guestbook）。

## 验证
1. `pnpm dev`：导航下拉出现「写作」→ 登录 → 新建测试文章（含标签/分类/草稿）→ 发布后 `/list/` 立即可见、文件落盘、`published` 为日期字面量。
2. 编辑该文修改标题/正文 → 更新生效；删除 → 文件消失、列表刷新。
3. 安全：错误密码拒绝、无 auth 头 curl 直调 API 返回 401、非法文件名/路径越界被拒。
4. `pnpm build`：/writing/ 不进 sitemap，prod 构建正常。
5. 视觉验收：渲染 login / list / editor / offline 与导航下拉截图交 judge 审查。
